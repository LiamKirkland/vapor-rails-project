# App Concept: Game Collection Manager

## Stories

### Feature 1 - Set up project foundation
User Story: Create all of the necessary files, classes, associations, migrations, etc 

### Feature 2 - Set up User login and authentication
User Story: As a user, I want to be able to create or login to an account. This way my game collection will be different from the collection of my friends or other users. This will include login/user creation pages.
*Details: Investigate Devise and figure out if I want to use that or custom authentication logic*

### Feature 3 - Set up game creation and associated pages
User Story: As a user, I want to be able to add games to my collection. If a game isn't currently in the app, I want the ability to add it to the website.

### Feature 4 - Add additional validations to game creation
User Story: As a user, I want to know if a game has already been created. When adding a game I should be alerted if there is a game with the same title already existing within the app. Any other validations that make sense should also be added here

### Feature 5 - Add a friends list
User Story: As a user, I would like to be able to connect with my friends on the app to see their collections/reviews/etc
*Details: A friends joins table is probably required, not sure how best to do this.*
